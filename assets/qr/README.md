# deryee.pro — 二维码存放目录

放在这里的图片会被「社交图标导航」的二维码弹窗调用。

## 需要的文件

| 文件名 | 对应入口 | 建议尺寸 |
| --- | --- | --- |
| `wechat-work.png` | 微信工作号（个人号 / 企业微信名片） | ≥ 600×600 |
| `wechat-mp.png` | 微信公众号（名片页 / 关注二维码） | ≥ 600×600 |
| `channels.png` | 微信视频号（视频号名片二维码） | ≥ 600×600 |

## 获取方式

- 微信工作号：微信 → 我 → 头像 → 我的二维码 → 保存图片
- 微信公众号：公众号后台 → 设置 → 账号详情 → 二维码 → 下载
- 视频号：视频号主页 → 右上角 → 我的二维码 → 保存图片

> 图片建议保留足够的白边，弹窗会以 200×200 的容器展示（`object-fit: contain`）。
> 文件请放在本目录下，文件名需与上表完全一致，`assets/social.js` 会自动按相对路径加载。
